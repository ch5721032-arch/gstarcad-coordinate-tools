# Contributing

Thanks for your interest in this project!

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-idea`)
3. Commit your changes with a clear message
4. Open a pull request

## Guidelines

- Keep scripts simple and dependency-free where possible
- Add a short usage comment at the top of every script
- Test your script in GstarCAD or another DWG-based CAD platform
- Update the README table when you add or change a script

## Reporting issues

Open an issue with the script name, the exact error message, and the steps to
reproduce. Screenshots and sample drawings are always welcome.
